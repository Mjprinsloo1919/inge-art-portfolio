# Inge — Art Portfolio

A responsive, single-page portfolio for showcasing Inge's paintings. Built with plain HTML, CSS and JavaScript; no build tools or dependencies required.

## Preview locally
Open `index.html` in a browser.

## Add Inge's paintings
The gallery currently uses tasteful abstract colour panels as **temporary placeholders**, not photographs of Inge's actual work.

1. Create an `images` folder in the repository.
2. Add the painting photographs, for example `images/painting-01.jpg`.
3. In `index.html`, add an image element for the featured artwork if desired.
4. In `script.js`, add an `image` property to each painting object and update the gallery rendering to display that image in place of the placeholder panel.
5. Update each painting's title and category to match the real artwork.

For best results, photograph paintings straight-on in soft natural light and use reasonably high-resolution JPG or WebP images.

## Personalise the site
- Replace the introductory text in the About section of `index.html` with Inge's own story.
- Replace `hello@example.com` with the email address she wants visitors to use.
- Change the painting titles and categories in `script.js`.
- Edit colours and typography in `styles.css`.

## Publish with GitHub Pages
1. Open the repository on GitHub and choose **Settings → Pages**.
2. Under **Build and deployment**, select **Deploy from a branch**.
3. Select the `main` branch and `/ (root)`, then save.
4. GitHub Pages will publish the site at the Pages URL shown in Settings → Pages.

The site is static and can also be hosted by Netlify, Cloudflare Pages or any standard static web host.
